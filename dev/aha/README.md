# AHA 공통 기반 개발

AHA 공통은 독립 도구를 Rhino 플러그인으로 묶는 기반이다. 플러그인·명령·등록 패널, 문서와 작업의 수명, MCP 통신, 빌드·설치를 소유한다. 각 도구의 업무 규칙과 형상 계산은 해당 도구에 둔다.

사람의 직접 사용과 MCP 호출은 같은 도구 서비스를 사용한다. 공통 기반은 호출 경로와 실행 환경을 연결하며 특정 AI 클라이언트의 동작을 업무 계약에 포함하지 않는다. 객체 정보의 원본은 [Info 계약](../info/contract.md)을 따르고 별도의 모델 원장이나 객체 간 동기화는 만들지 않는다.

## 개발 문서

| 문서 | 읽을 때 |
|---|---|
| [계약](contract.md) | 대상 식별·문서 변경·비동기 작업·실패 동작을 사용하거나 바꿀 때 |
| [구조](architecture.md) | 플러그인·패널·서비스·MCP의 연결과 책임을 바꿀 때 |
| [MCP](mcp.md) | 통신·도구 등록·입력 변환·결과 전달을 다룰 때 |
| [빌드와 검사](build-and-test.md) | 환경 준비·패키지·설치본·회귀 검사를 다룰 때 |
| [History](HISTORY.md) | 관련 결정의 이유나 과거 오류를 조사할 때만 |

## 구현과 변경 범위

- [`rhino/`](../../src/aha/rhino/): 플러그인 등록, 패널 연결, 문서 접근, 작업 관리, MCP 서버 제어.
- [`mcp/`](../../src/aha/mcp/): HTTP·JSON-RPC 처리, 도구 설명·입력 스키마, 도구 서비스 호출.
- [`package/`](../../src/aha/package/): manifest·아이콘 도구모음·Yak 생성.
- [`assets/logo/`](../../src/aha/assets/logo/): 로고 SVG와 편집 원본. README·패널·AHA 아이콘은 mono를 사용한다.
- [`checks/`](../../src/aha/checks/README.md): 공통 정책·통신·문서·등록·패키지·검사 실행기 검증.

공통 상태·문서 수명·실행 흐름을 바꾸면 연결된 도구와 전체 회귀 검사를 확인한다. 도구별 입력과 계산 규칙을 수정할 때는 [개발 인덱스](../index.md)에서 해당 소유자의 계약과 검사로 이동한다. [사용자 안내](../../docs/aha/README.md)는 설치와 사용에 필요한 설명을 담당한다.
