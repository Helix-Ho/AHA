# EumCrawl 계약

한 번에 PNU 하나를 조회한다. 원문 구조 읽기와 휴리스틱 후보 미리보기는 별도 기능이며, 미리보기에서 명시적으로 선택한 항목만 Info에 적용한다. 조회는 객체를 바꾸지 않는다. 여러 필지의 면적이나 법규를 합산·통합 판정하지 않는다.

## 입력과 결과

| 서비스 | 입력 | 결과 |
|---|---|---|
| `EumService.ReadAsync` | Rhino 문서, PNU, 선택적 `sections`, 취소 토큰 | 수치 선택 없이 구조화한 출처 자료. 객체·캐시를 만들지 않음 |
| `EumService.PreviewAsync` | Rhino 문서, 선택적 객체 GUID, 선택적 PNU, `parcelIndex`, 취소 토큰 | 조회 결과와 객체 정보의 비교 미리보기 JSON |
| `EumService.Apply` | 문서, 객체 GUID, 미리보기 식별자를 담은 JSON, 적용 필드명 목록 | Info 공통 쓰기로 저장한 전체 Info JSON |
| `EumService.Discard` | 미리보기 JSON | 메모리의 해당 미리보기만 제거 |

조회에는 열린 Rhino 문서가 필요하다. 객체 없이 조회할 수 있지만 이때는 PNU를 입력해야 하며 적용은 불가능하다. PNU는 ASCII 숫자 19자리이고 11번째 문자는 `1` 또는 `2`여야 한다. 주소만으로 검색하는 기능은 제공하지 않는다.

객체가 있으면 PNU 생략 시 선택한 원필지 슬롯의 저장된 PNU를 사용한다. 별도 PNU를 입력해 다른 필지를 조회할 수도 있다. 객체는 Topo 산출물이나 대지 지정 Curve일 필요가 없다. 기존 Info가 있으면 현재 저장 형식을 검증하며 잘못된 값은 먼저 Info에서 정정해야 한다. `parcelIndex`는 0부터 시작하고 원필지가 없다면 0만 유효하다. 기존 목록의 범위를 넘어 새 슬롯을 지정하지 않는다.

미리보기의 주요 결과는 다음과 같다.

| 필드 | 의미 |
|---|---|
| `fields` | 반영 이름별 후보 객체. 아래 상태·값 규칙을 따른다. |
| `parcels` | 조회한 필지 한 건의 PNU·주소·열람 URL·원문·필지 속성·규제 후보·출처·경고 |
| `current_data`, `parcel_index` | 조회 시작 시 대상의 data와 선택 원필지 위치 |
| `sources`, `warnings` | 요청별 출처·기준일·조회시각·항목 원문과 취득 실패 안내 |
| `document_id`, `object_id` | 조회 대상. 객체 없는 조회의 `object_id`는 `null`이다. |
| `can_apply` | 조회 시작 시 객체의 편집 가능 여부. 이후 상태까지 보장하지 않는다. |
| `preview_id` | 객체가 있을 때 발급하는 적용용 식별자 |

후보는 `status`, `text`, `requires_confirmation`을 담는다. `candidate`는 구조화한 `value`가 있지만 확인이 필요한 후보, `unknown`은 미확인, `conditional`은 단일 값으로 적용할 수 없는 조건부 결과다. 미확인 값을 0이나 제한 없음으로 채우지 않는다.

성공한 조회의 `parcels[0].url`은 조회한 PNU의 토지이용계획 열람 페이지다. 객체 없는 조회나 개별 규제 취득의 부분 실패에도 반환하므로, 호출자는 후보 수치·조건·한계와 함께 사용자에게 원문 링크를 제공할 수 있다. `sources[].url`에는 내부 자료 요청 URL도 있으므로 사용자 열람에는 `parcels[0].url`을 사용한다.

## 원문 구조 읽기

`ReadAsync`는 `sections`에 `parcel`, `bcr_far`, `height_floors`, `building_line`, `open_space` 중 읽을 항목을 받는다. 생략하면 전체이며 빈 배열·중복·모르는 항목은 거절한다. 필지 식별을 위한 상세 페이지는 항상 한 번 취득하고, 선택한 규제 항목만 추가 요청한다. 이 경로는 아래 최솟값 정책이나 높이 후보 파싱을 호출하지 않으며 Info를 읽거나 쓰지 않고 적용용 미리보기도 발급하지 않는다.

결과는 `document_id`, `pnu`, `address`, 사용자 열람 `url`, 상세 페이지의 `retrieved_at`, `status`, `sections`, `warnings`, `notice`다. `status`는 모든 요청 항목의 상태가 `ok`이면 `ok`, 하나라도 `failed`·`no_content`이면 `partial`이다. 문서 닫힘·취소와 상세 페이지 식별 실패는 결과로 바꾸지 않고 호출 실패로 전달한다.

각 section은 `name`, `title`, `source_url`, `retrieved_at`, `reference_date`, `status`, `blocks`를 갖는다. 구조화 블록을 반환하면 `ok`, 블록이 없으면 `no_content`, 취득·추출 실패면 `failed`이며 실패에는 `error`를 붙인다. `ok`는 모든 수치나 조건을 확인했다는 뜻이 아니다. 계산 전 UI의 블록·셀 상태 `not_computed`는 아래와 같이 별도로 표시하며, 이 경고만으로 section이나 결과 전체를 `partial`로 바꾸지 않는다. 빈 본문이나 일부 실패는 규제 없음·제한 없음이 아니다. 기준일은 응답에 있을 때만 문자열로 반환한다.

- `blocks`는 `paragraph`, `heading`(`level` 포함), `list_item`, `table`로 구성한다. 텍스트와 줄바꿈·조건을 보존하며 수치를 선택·계산하지 않는다.
- 표는 `caption`이 있으면 보존하고 `rows[].cells[]` 순서를 유지한다. 셀은 `header`, `rowspan`, `colspan`, 내부 `blocks`를 갖고 원문 `id`, `headers`, `scope`가 있으면 보존한다. 병합 셀을 중복 숫자로 펼치지 않으며 중첩 표는 해당 셀 내부에 둔다. 표 내부에서 행 밖에 적힌 조건 문구는 `notes`로 남긴다.
- `parcel`은 상세 페이지의 지목·면적·지역지구·별도 확인사항 셀을 항목명과 함께 보존한다. 내비게이션·지도 범례·중복 팝업 설명은 필지 사실로 포함하지 않는다.
- 텍스트 블록의 `links`는 원문 링크 이름과 HTTP(S) URL이다. 상대주소는 출처 기준으로 풀고 실행 주소·인증정보가 포함된 주소는 제외한다. 링크 대상은 추가로 읽지 않는다.
- HTML 입력값·스크립트·스타일·명시적인 숨김 요소는 본문이 아니다. CSS를 렌더링하거나 JavaScript를 실행하지 않으며 도식·이미지 내용을 해석하지 않는다. 따라서 브라우저 화면 전체의 복제나 법적 적용성 판정은 아니다.
- JavaScript가 채우는 산출 도식·면적·소재지 표시의 초기값은 규제 자료로 반환하지 않는다. 해당 블록·표 셀에 `status: "not_computed"`와 미확인 이유를 두고 결과 `warnings`로 알린다. 규제 표의 실제 0%와 원문 조건은 그대로 보존한다.
- 응답·본문·구조 한도를 넘으면 해당 항목을 `failed`로 반환하고 일부 문장을 잘라 정상 결과로 내보내지 않는다. 규제 본문은 30,000자, 구조화 자료의 항목별 텍스트 합계는 100,000자 이내다.

## 수치와 필지 정보

미리보기의 건폐율·용적률은 해당 조례 셀에서 백분율을 읽어 최솟값을 JSON 숫자로 제공한다. 조건별·지역별 복수 값과 범위 표현도 이 정책을 따른다. 0%가 명시되면 0도 값이다. 다른 항목이나 숨김 입력의 값은 섞지 않는다.

현재 파서의 후보 범위는 건폐율 0~100%, 용적률 0~10,000%다. 이는 파싱 범위이며 법적 허용값 판정이 아니다. 유효한 백분율을 찾지 못하면 미확인이다. 결과에는 `method: "minimum_percentage"`, 읽은 후보의 `observed_percentages`, 방식·한계를 설명하는 `notice`, 확보한 항목 원문을 남긴다. 원문 조건을 검토하지 않고 법규 확정값으로 사용할 수 없다는 설명을 MCP 도구 설명에도 유지한다.

최고높이·최고층수는 대응하는 표 항목의 명확한 단일 값만 후보로 만든다. 현재 파서 범위는 높이 0 초과 10,000m 이하, 층수 1~1,000의 정수다. 조건부·복수 표현은 단일 값으로 줄이지 않는다. 건축선·대지 안의 공지는 경계·용도 조건이 필요하므로 현재 `setback_m` 숫자 후보를 만들지 않으며 본문이 있으면 조건부로 남긴다.

지목·토지이음 표시 면적·용도지역지구는 상세 페이지에서 읽는다. 면적은 Rhino 형상 면적과 별개다. 용도지역지구는 `national_plan`, `other_laws` 그룹의 원문을 보존한다. 그 밖의 제한·조건은 참고 메모 후보에 포함한다.

## 선택 적용

| 적용 필드명 | 저장 위치·동작 |
|---|---|
| `parcels.identity` | 선택 원필지의 `pnu`, `address`를 짝으로 교체 |
| `parcels.land_category` | 해당 필지의 지목 |
| `parcels.area_m2` | 해당 필지의 자료상 면적(㎡) |
| `parcels.land_use_zones` | 확인된 `national_plan`, `other_laws`만 갱신. 미확인 그룹과 확장 항목은 보존 |
| `bcr_percent`, `far_percent` | data의 백분율 숫자 |
| `setback_m`, `max_height_m`, `max_floors` | data의 이격거리·높이(m)·층수. 후보가 없는 항목은 적용 불가 |
| `notes` | 기존 메모를 조회한 참고 메모로 교체. 최솟값 정책·한계·수치·조건 원문을 포함 |

빈 목록, 지원하지 않는 필드명, 값 없는 미확인·조건부 항목을 적용하도록 요청하면 거절한다. 선택하지 않은 값, 다른 원필지, 확장 정보는 유지한다. 원필지가 없는 객체는 0번 항목을 만들 수 있다. 원필지 배열의 보존과 Undo는 [Info 계약](../info/contract.md)을 따른다.

검색 PNU를 바꿔도 객체의 주소·PNU는 자동 변경하지 않는다. 사용자가 `parcels.identity`를 선택하지 않고 다른 정보만 반영할 수 있다. 이는 조회 대상과 저장된 주소가 달라도 허용하는 명시적 선택이다. 출처 자료는 조회 결과에 두며 `data.sources`를 자동으로 쓰지 않는다. 기존 출처 확장 정보는 보존한다.

### 미리보기 수명과 실패

객체의 미리보기는 문서·객체·원필지 위치·조회 당시 원본 JSON에 묶인다. 메모리 보관 기간은 30분이고 최대 100개다. 만료 정리·한도 확인·등록을 한 임계영역에서 처리한다. 재시작·만료·명시적 폐기·성공한 적용 이후에는 새로 조회해야 한다.

적용값은 서버에 보관한 미리보기에서만 가져온다. 호출자가 받은 후보 JSON을 고쳐 보내도 저장값이 바뀌지 않는다. 다른 대상, 오래된 원본, 만료·소비된 식별자는 거절한다. 적용 시 편집 가능 여부와 원본 충돌을 다시 확인하며 성공한 뒤에만 미리보기를 소비한다.

상세 페이지 실패나 PNU 불일치는 조회 전체 실패다. 개별 규제 요청 실패는 경고와 해당 정보의 미확인으로 남기며 확보된 다른 결과는 사용할 수 있다. 취소와 대상 문서 닫힘은 정상 조회 결과로 바꾸지 않는다. 실패해도 Info의 수동 편집 기능은 독립적으로 사용할 수 있다.

## 의존 계약과 검사

외부 공급원은 토지이음이며 VWorld KEY·Topo·AI 호출에 의존하지 않는다. 저장 형식·쓰기·보존은 [Info](../info/contract.md), 문서 실행은 [공통 계약](../aha/contract.md)이 소유한다. 패널과 MCP는 같은 EumService를 호출한다.

MCP는 다음 입력을 공통 서비스로 연결한다.

| 공개 기능 | 입력과 서비스 연결 | 도구 결과 |
|---|---|---|
| `aha_eum_read` | 필수 `document_id`, `pnu`, 선택적 `sections` → `ReadAsync` | 작업 핸들. 완료된 `result`는 위 원문 구조이며 후보·적용 토큰 없음 |
| `aha_eum_preview` | 필수 `document_id`, 선택적 `object_id`, `pnu`, `parcel_index`(기본 0) → `PreviewAsync` | 우선 `job_id`를 포함한 작업 상태. `aha_job_status`의 완료된 `result`가 위 미리보기 JSON이다. |
| `aha_eum_apply` | 필수 `document_id`, `object_id`, `preview: { "preview_id": "조회 결과의 식별자" }`, 적용 필드명 배열 `fields` → `Apply` | 저장한 전체 Info JSON |

`preview`에는 식별자만 전달하며 후보·출처·기존값을 다시 보내지 않는다. 조회에서 PNU 생략이 가능한 조건과 적용 대상·필드 규칙은 위 서비스 계약과 같다. 작업 조회·취소와 응답 형식은 [MCP 규약](../aha/mcp.md)을 따른다. 공통 작업의 수명과 적용용 미리보기의 30분 수명은 서로 다르다.

취득·파싱·비동기 연결은 [구조](architecture.md), 각 규칙과 자동 판정의 연결은 [검사 안내](../../src/eum-crawl/checks/README.md)를 참고한다.
