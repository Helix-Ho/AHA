# Model Context Protocol

외부 클라이언트가 서버의 도구를 발견하고 호출하는 프로토콜의 공식 규격이다. 검토일은 2026-10-05이며 AHA가 협상하는 버전 중 `2025-11-25`의 [Tools 규격](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)을 확인했다. 별도 SDK나 규격 원본 파일은 포함하지 않는다.

`tools/list`의 도구 설명·입력 스키마, `tools/call`의 결과·오류, 선택적 출력 스키마와 구조화 결과의 의미를 참고한다. Markdown 계약 문서는 클라이언트에 자동 전달되지 않으므로 호출자가 알아야 할 업무 제약은 실제 도구 등록 설명에도 있어야 한다.

AHA의 지원 범위와 실제 응답 형식은 [MCP 안내](../../aha/mcp.md), 업무 의미는 각 소유자의 [계약](../../index.md)이 정한다. 규격에 있는 모든 기능을 AHA가 구현한 것은 아니며 출력 스키마도 현재 등록하지 않는다. 후속 규격이 발표되어도 AHA의 지원 버전이나 동작을 자동으로 바꾸지 않는다.
