# VWorld

[개발자 안내](https://www.vworld.kr/dev/v4apiRefer.do)와 공개 3D SDK를 Topo의 실행 시 자료 취득에 참고했다. 원본 clone은 없다. 현재 엔드포인트·공식 문서 링크·응답 의미는 [Topo 데이터와 한계](../../../docs/topo/data.md)에 모으며 여기서 중복 관리하지 않는다.

지적도·주소 검색·건물 속성 명세와 SDK의 DEM 전달 방식을 구분해 조사했다. 지적도를 기준으로 도로 영역을 정하고 확보한 속성만 기록하는 [Topo](../../topo/README.md)의 기반이다. 자료 취득 방식의 선택 이유는 [Topo 기록](../../topo/HISTORY.md)에 남겼다.

2026-10-05 정리 기준의 검토 범위다. 특히 DEM 전달 경로는 공식 독립 다운로드 API로 확인되지 않은 실험 어댑터다. SDK가 전달하는 데이터를 읽었다는 사실은 수직 기준·전국 완전성·모델 가공 및 제공의 이용 조건을 확정하지 않는다. 요청을 변경할 때 현재 공급 조건을 다시 확인한다.

공개 회귀 입력은 [Topo 검사](../../../src/topo/checks/README.md)의 합성 자료다. 취득 원본과 출처·해시는 Git 제외 영역인 `.local/test-data/topo/`에서만 관리한다. KEY·인증 응답·개인 설정은 참고 자료에 저장하지 않는다.

## 프로그램과 데이터의 공개 조건

2026-10-11 확인한 [이용약관](https://www.vworld.kr/v4po_prcint_a001.do)은 제13조에서 약관을 준수하는 독립 프로그램 배포와 이용 표기를 다루고, 제14·18·19조에서 3차원 공간정보 복제·유출, 제공 방식 외 다운로드와 데이터 저장·제공을 제한한다. [저작권정책](https://www.vworld.kr/v4po_prcint_a006.do)은 개별 공공데이터의 자유이용도 인정한다. [연속지적도](https://www.data.go.kr/data/15056910/openapi.do)의 이용허락범위는 제한 없음으로 표시되지만 이를 SDK DEM이나 모든 자료의 허락으로 확대할 수는 없다.

SDK DEM의 플러그인 직접 취득, 가공 모델의 저장·상업 이용·타인 제공, 실제 원천 fixture의 공개 재배포는 운영기관의 해당 자료·경로에 대한 허용 근거를 확인해야 한다. API 연결 코드 공개와 원천·가공 데이터의 공개는 구분한다. KEY가 유효하거나 데이터를 가공했다는 사실만으로 이용허락이 확인되지는 않는다. 공개 대상은 현재 파일뿐 아니라 Git 이력의 이전 경로도 포함한다.

인증키는 발급받은 회원 본인만 사용하며 타인에게 양도할 수 없다. 사용자별 KEY를 받는 독립 프로그램 배포는 제13조의 약관 준수 조건 아래 가능하지만, 이것이 영리 이용의 허락을 대신하지는 않는다. 제13·20조의 운영기관 동의 조건과 자료별 이용 범위를 따로 확인한다.
