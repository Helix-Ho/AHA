# 버전 기록과 공개 라이선스

2026-10-11에 버전 설명과 소스·패키지 공개 조건을 검토했다. 외부 파일 사본은 보관하지 않는다.

- [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/): 사람이 읽을 주요 변경을 버전별 최신 순으로 관리하는 방식을 참고했다. AHA의 [버전 기록](../../../CHANGELOG.md)은 기능·검증 환경·한계를 요약하며 Git 로그나 개발 History를 대체하지 않는다.
- [GitHub 라이선스 안내](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository): public 저장소와 재사용 허락은 별개다. AHA의 [MIT License](../../../LICENSE)는 외부 라이브러리 고지나 데이터 이용조건을 대신하지 않는다.
- [MIT](https://opensource.org/license/mit) · [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0.html): 허용적 라이선스의 재배포·고지 조건과 Apache의 명시적 특허 허여를 비교하는 원문이다. AHA에는 MIT를 적용한다.
- [GitHub Releases](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases): 소스 공개와 설치 파일의 Release 제공은 별도 작업이다. AHA의 현재 빌드·패키지 구성은 [빌드 안내](../../aha/build-and-test.md)가 소유한다.

배포 라이브러리는 [Clipper2](../Clipper2/README.md)·[NetTopologySuite](../NetTopologySuite/README.md), 외부 자료는 [VWorld](../VWorld/README.md)·[토지이음](../Eum/README.md)의 출처와 이용조건을 각각 확인한다.

README의 테마별 로고는 [GitHub의 `picture` 지원 안내](https://github.blog/changelog/2022-08-15-specify-theme-context-for-images-in-markdown-ga/)(2022-08-15, 2026-10-11 확인)를 참고한다. 밝은 테마와 기본 표시에는 검정 SVG, 어두운 테마에는 흰색 SVG를 사용한다. 다른 Markdown 뷰어의 테마 전환 지원은 보장하지 않는다.
