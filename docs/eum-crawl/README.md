# EumCrawl

PNU로 토지이음 공개 화면을 조회하고, 선택한 Rhino 객체의 현재값과 비교해 필요한 항목만 `aha.info`에 반영한다. 초기 계획에서 필지 정보와 규제 후보를 빠르게 확인하는 데 사용할 수 있다. 객체 없이도 조회할 수 있다. AI·로그인·VWorld KEY가 필요하지 않으며 Topo에 의존하지 않는다.

자료 출처는 국토교통부의 [토지이음](https://www.eum.go.kr/)이다. 패널 하단의 출처 링크에서 토지이음 홈페이지를 열 수 있다.

현재 **실험 기능**이다. 토지이음의 공개 화면과 내부 HTML 형식에 의존한다. 공식 OpenAPI나 법규 판정기가 아니며, 전체 법령·별표를 해석하거나 전국 필지·규제 유형의 완전성을 검증한 상태는 아니다.

패널과 후보 조회의 건폐율·용적률은 각각 조례 항목에 표시된 백분율의 **최솟값**을 참고 수치로 사용한다. 특례·용도지역 중첩·면적 가중평균 등의 적용 여부를 판정하지 않으므로 실제 허용값과 다를 수 있다. 이 동작과 한계를 패널에 항상 표시하고 MCP 도구 설명·조회 결과에도 제공한다. 토지이음 열람 링크에서 원문을 확인할 수 있다.

## 패널

Rhino 등록 패널 한 경로로 연다. 탭의 위치와 배치는 Rhino Container가 관리하며 AHA가 별도 창을 만들거나 강제 플로팅하지 않는다.

- **선택 없음:** 기존값은 `—`로 표시하고 반영 체크는 비활성화한다. 신규 PNU를 입력하고 `검색`한다. 조회만 하며 객체를 변경하지 않는다.
- **객체 하나 선택:** 표는 `항목 | 기존 | 신규 | 반영` 네 열이다. 양끝 열은 좁게, 가운데 두 값 열은 같은 폭으로 배치한다. 기존값은 읽기 전용이며 주소·PNU도 같은 열을 사용한다. 주소 입력부와 결과 표 사이에 검색·열람 버튼을 둔다. 선택 객체가 바뀌면 그 객체의 주소·PNU와 속성을 자동으로 읽는다. 여러 원필지가 있으면 먼저 대상 원필지를 고른다.
- **여러 객체 선택:** 패널을 비활성화한다.
- **검색:** 오른쪽 PNU로 조회한다. 입력 변경이나 검색만으로 객체가 바뀌지 않는다. 현재 주소 검색은 제공하지 않는다. 토지이음의 주소 검색에는 후보 검색·선택·PNU 확정 절차가 추가로 필요하기 때문이다. 주소는 기존 정보와 검색 결과에서 표시한다.
- **토지이음 열람:** 현재 검색이 성공한 뒤에만 활성화하며, 검색한 PNU의 토지이용계획 페이지를 기본 브라우저에서 연다. 검색 입력 변경·실패 시 이전 결과와 열람 가능 상태를 지운다.
- **반영:** 추출된 후보는 기본으로 모두 체크한다. 건폐율·용적률은 조건부·복수 값도 백분율 최솟값을 숫자 후보로 제공한다. 미확인 항목이나 값 없이 조건만 제공된 항목은 체크할 수 없다. 남겨둔 체크 항목만 반영한다. 주소·PNU는 한 쌍의 별도 항목이며 이를 해제하면 기존 주소·PNU를 유지한 채 다른 필지에서 얻은 값을 기록할 수도 있다. 이는 사용자의 선택으로 허용한다.

조회 중 선택 객체·원필지·문서·속성이 바뀌면 해당 화면의 이전 조회를 취소하거나 폐기한다. 원래 객체에서 받은 결과를 새 선택 객체에 적용하지 않는다. 잠긴 객체·읽기 전용 문서는 조회할 수 있지만 반영하지 않는다. 저장은 [Info](../info/README.md)의 공통 쓰기와 검증을 사용하고 Rhino Undo를 지원한다.

## 가져오는 정보

| 항목 | 의미 |
|---|---|
| 주소·PNU | 검색한 필지의 식별 정보. 선택 반영 시 한 쌍으로 변경 |
| 지목·면적 | 토지이음 표시 값. 면적은 ㎡이며 Rhino 형상 면적과 다를 수 있음 |
| 용도지역·지구 | 국토계획법과 다른 법령에 따른 지정을 각각 원문으로 보관 |
| 건폐율·용적률 | 각각 조례 셀에 표시된 백분율의 최솟값 |
| 높이·층수 | 명확한 단일 값만 후보로 제공. 조건부·모호한 값은 숫자로 반영하지 않음 |
| 이격 | 건축선·대지 안의 공지 원문을 참고 메모로 제공. 이격거리 숫자 반영은 지원하지 않음 |
| 참고 메모 | 별도 확인사항, 최솟값 선택 방식과 한계, 원문 조건 |

토지이음 상세 페이지에서 소재지와 필지 정보를 읽고, 본문에 값이 없는 건폐율·용적률·높이·층수·건축선·대지 안의 공지 영역을 추가로 조회한다. 일부 영역을 가져오지 못하면 해당 항목은 미확인으로 남기고 경고한다. PNU 일치 확인 자체가 실패하면 검색 실패다.

미리보기는 30분 동안만 유효하다. 다른 객체·원필지로 바꾸거나 기존 정보가 수정됐거나 결과를 이미 적용했다면 다시 검색한다. 메모 반영은 기존 메모를 교체한다.

## MCP 사용

`aha_eum_preview`로 조회하고 `aha_job_status`에서 완료된 결과를 받는다. 조회만으로 객체 정보가 바뀌지 않는다. 성공한 결과의 `parcels[0].url`은 해당 필지의 토지이용계획 열람 링크이므로, AI는 후보 수치와 한계를 설명하면서 이 링크를 사용자에게 전달할 수 있다. 일부 규제 항목을 가져오지 못했더라도 상세 페이지 확인에 성공했다면 열람 링크는 제공된다.

`aha_eum_read`는 PNU의 토지이음 필지 정보·건폐율/용적률·높이/층수·건축선·대지 안의 공지를 읽는다. 필요한 항목만 선택할 수 있고, 최솟값을 선택하지 않은 표·조건·문단과 원문 링크를 반환한다. AI가 조건을 읽는 데 사용할 수 있지만 법규 적용성을 확정하는 도구는 아니다. 객체 속성을 변경하지 않는다.

일부 항목의 조회 실패나 본문 부재는 결과에 구분되어 표시된다. 브라우저가 나중에 계산하는 산출 도식과 면적은 초기 숫자를 쓰지 않고 미확인으로 알린다. 브라우저 스크립트·이미지·링크된 다른 페이지의 내용은 포함하지 않으므로, 필요한 경우 반환된 토지이용계획 링크에서 확인한다. 기존 패널 및 `aha_eum_preview`의 숫자 후보는 계속 해당 항목 백분율의 최솟값을 사용한다.
