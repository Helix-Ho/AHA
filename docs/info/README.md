# Info — 객체 정보 편집

Rhino 객체 하나의 `aha.info` UserText를 읽고 만들고 수정하거나 삭제한다. 입력 출처와 무관하게 일반 객체에는 정보를 붙이고, 유효한 닫힌 Curve나 닫힌 Brep·Extrusion 입체에는 **대지로 지정**을 켤 수 있다.

## 사용

AHA의 Info를 열고 Rhino에서 객체 하나를 선택한다. AHA의 버튼과 `AHAInfo` 명령은 같은 Rhino 등록 패널을 열며 위치·크기·도킹 상태는 Rhino Container가 관리한다. 편집 상태는 문서별로 구분한다. 종류, 메모와 추가 항목을 입력한 뒤 **저장**한다. 원필지의 주소·PNU·지목·면적·용도지역·지구는 대지 지정 여부와 무관하게 조회·편집할 수 있다. 대지로 지정하면 건폐율·용적률·이격거리·최고 높이·최고 층수 입력란도 나타난다. 모르는 값은 비워둔다. 원필지가 여러 개이면 **새 필지**로 각각 입력하며 필지 편집은 저장할 때도 반영된다.

**면적 (㎡)**은 필지별 입력 면적이며 Rhino 형상에서 계산한 면적과 별개다. 필지별로 보존하고 합산하지 않는다. 용도지역·지구는 국토계획법과 다른 법령의 두 입력란으로 구분하며 조건과 접합 여부 등의 원문을 유지한다. 빈칸은 미확인이며 ‘제한 없음’을 뜻하지 않는다. 직접 입력하거나 다른 도구가 기록한 값을 이 입력란에서 확인·수정할 수 있다.

추가 항목은 문자·숫자·참/거짓으로 입력할 수 있고, 목록·객체는 JSON으로 편집한다. **고급 JSON 편집**은 현재 문서를 보여주고 JSON merge patch를 적용한다. `null`은 해당 항목 삭제이며 배열은 전체 교체한다. 미입력은 값 없음으로 취급하며 0을 미입력으로 바꾸지 않는다. 수치의 단위는 표시된 단위와 필드 이름을 따른다. Info는 입력한 법규 값의 적법성이나 최신성을 판정하지 않는다.

**대지 지정 해제**는 입력 정보를 보존한다. **정보 삭제**는 해당 객체의 `aha.info`만 제거하고 형상과 다른 UserText는 유지한다. 저장과 삭제는 Rhino Undo / Redo를 지원하며, 3dm 저장 시 객체와 함께 보존된다.

편집 중 선택이 바뀌면 현재 편집을 유지한다. 저장하거나 **편집 취소 / 새로 읽기**를 눌러 새 선택으로 이동한다. 다른 도구가 정보를 바꿨으면 저장을 거절하고 새로 읽도록 안내한다. 잠긴 객체·레이어, 참조 객체와 읽기 전용 문서는 편집할 수 없다. 지원하지 않는 Info 버전은 수정하거나 삭제하지 않는다.

## 항목의 의미

- **종류(kind)**는 AHA의 의미상 분류다. Rhino 형상 타입을 바꾸지 않는다. 정보가 없는 일반 객체는 기본 `object`로 표시한다.
- **대지(site)**는 유효한 닫힌 Curve 또는 닫힌 Brep·Extrusion 입체에 지정할 수 있다. 해제해도 입력 정보는 유지한다.
- **원필지**는 주소·19자리 PNU를 짝지어 보관한다. 여러 원필지를 가진 경계는 여러 행으로 관리한다.
- **지목·면적·용도지역·지구**는 필지별 입력 정보다. 면적(㎡)은 Rhino 형상에서 자동 계산한 면적과 별개다. 자료가 없으면 미확인으로 둔다.
- 건폐율·용적률은 %, 이격거리·최고 높이는 m, 최고 층수는 정수다. 빈 값은 미확인이며 0 또는 제한 없음으로 해석하지 않는다.
- 메모와 추가 항목은 필요에 따라 작성할 수 있다. Info는 특정 출처를 요구하거나 법규를 판정하지 않는다.

Topo의 건물 XY 경계와 입체에 같은 정보가 기록될 수 있지만, 생성 후 두 객체의 수정은 자동 동기화되지 않는다. 객체를 복사해도 원본과 복사본의 정보는 각각 독립적이다.
