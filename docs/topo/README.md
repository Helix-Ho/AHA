# Topo

한국의 지형·필지·도로·건물을 Rhino 모델로 만든다. `AHA → Topo` 또는 `AHATopo`로 연다. 새 자료 취득에는 [Setting](../setting/README.md)에 저장한 VWorld KEY가 필요하다.

상단에는 KEY 등록 상태와 마지막 검증 결과를 표시한다. KEY가 없으면 지도 대신 발급·등록 안내가 나타나며 검색과 모델 입력을 잠근다. 같은 줄의 Setting 버튼으로 설정을 열 수 있다. KEY 등록은 서비스 사용 가능성의 확인과 별개다.

## 모델 만들기

1. [Setting](../setting/README.md)에서 본인의 VWorld 키를 저장한다. Topo는 저장된 키를 사용하며 환경변수나 `.env`를 자동으로 읽지 않는다.
2. 주소를 검색하면 검색창 아래에 후보 목록이 펼쳐지고, 후보를 선택하면 닫힌다. 지도에서 필지를 왼쪽 클릭해 추가할 수도 있다. 지도 아래 필지 목록의 각 **해제** 버튼이나 지도에서 다시 왼쪽 클릭하면 개별 해제되고, 선택 요약 옆의 **전체 해제**를 누르면 모두 해제된다. 선택이 없으면 안내 문장만 표시한다. 여러 필지를 선택할 수 있으며 인접 필지는 하나의 대지로 합치고 떨어진 필지는 독립 대지로 유지한다.
3. 모델의 가로·세로 범위를 정한다. 선택 전체의 중심을 기준으로 하며 각 50~3,000m, 기본 400m다. 필지를 선택하면 필요한 만큼 자동 확장한다. 직접 입력한 범위가 대상지를 포함하지 못하면 최소 범위를 안내한다. 조절 버튼과 ↑/↓는 방향별 다음 100m 배수로 이동하며 직접 입력한 수치는 그대로 사용한다.
4. **근접 영역**의 반경·깊이, 파라펫과 Contour를 설정한다. 근접 영역은 기본 ON이며 지형 입체와 건물 Extrusion을 만든다.
5. 필요하면 **고급 설정**을 펼쳐 지형·건물 형식, 지형 표본 간격, 도로·건물 설정을 확인한다. 형식은 기본 Mesh이며 근접 영역이 켜져 있으면 원경에 적용된다. **연산**을 누른다. 입력이 고정되고 백그라운드에서 형상을 준비한다. 이때 Rhino 객체·레이어는 아직 생기지 않으며 다른 모델 작업을 계속할 수 있다.
6. 연산이 끝나면 준비 개수와 안내를 확인하고 **생성**을 누른다. 준비한 객체·레이어를 Rhino에 추가하며, 완료 후 패널의 **생성 완료**에서 생성 개수를, **안내**에서 처리 내용을 확인한다. 아래 **주의**에는 지형 자료의 한계를 표시한다.

지도는 드래그로 이동하고 휠 또는 +/−로 확대·축소한다. 휠 줌은 커서 위치를 기준으로 동작한다. 새 결과는 별도 상위 레이어에 추가되며 한 번의 Undo로 생성 결과를 되돌릴 수 있다.

문서마다 연산·준비 결과를 하나씩 보관한다. 설정을 바꾸려면 실행 중에는 **취소**, 준비 후에는 **준비 결과 폐기**를 누른다. 패널을 닫거나 다른 탭으로 옮겨도 작업은 유지되며, 다시 열면 상태와 입력 요약을 보여준다. MCP에서 시작한 작업도 같은 패널에서 생성·취소할 수 있다.

전체 모델·XY 연산에는 자동 시간 제한이 없다. 중단하려면 **취소**를 누른다. 개별 통신 제한과 지형 취득 한도(64타일·높이 표본 100만 개)는 유지한다.

준비 결과는 메모리에만 있으며 문서를 닫거나 Rhino를 종료하면 없어진다. 준비 후에는 KEY가 없어도 생성할 수 있다. 문서의 단위·허용오차가 바뀌면 다시 연산해야 한다. 다른 Rhino 명령이나 AHA 변경 작업이 진행 중이면 준비 결과를 유지하고 생성 재시도를 안내한다.

## MCP로 XY 평면 정보 만들기

`aha_topo_xy_prepare_start`는 선택 PNU와 지정한 범위에 대해 대지경계·주변 필지·도로 지목 필지·건물 윤곽을 Z=0 Curve로 준비한다. 가로·세로는 각각 기본 400m, 50~3,000m이며 도로 참조선 여부와 최소 건물 면적을 설정할 수 있다. 지형 높이·면·입체는 취득하거나 계산하지 않는다. 패널의 **연산**은 전체 모델 기능이다.

`aha_job_status`가 `ready`이면 `aha_topo_create`에 같은 작업 ID를 전달해 생성한다. 전체 모델도 `aha_topo_prepare_start → ready → aha_topo_create` 흐름을 사용한다. 생성 완료 전에는 실제 객체 식별자가 없으며, MCP 연결을 끊어도 작업은 유지된다. 연결 방법은 [AHA 안내](../aha/README.md)를 따른다.

결과는 표시되는 `aha_topo_…::XY` 아래 `TargetBoundary`, `ParcelBoundary`, `RoadBoundary`, `BuildingFootprints`로 나뉜다. 인접 선택 필지는 합치고 떨어진 대지는 구분한다. 대지 외곽은 Info의 대지로 지정하고, 구멍 경계는 대지 지정에서 제외한다. 대지는 확보한 상세 정보, 주변 필지·건물은 기본 정보를 기록한다.

선택 대지는 포함 범위를 검사하고 닫힌 경계를 보존한다. 주변 원천 선은 범위에서 자르되 범위를 따라 임의로 닫지 않는다. XY 선에는 100mm 모델 정리를 적용하지 않는다. **Z=0은 실제 표고가 아니며**, 도로선은 도로 지목 필지의 경계로 포장면·차선과 다르다. 생성하지 않은 건물 높이를 계산해 기록하지 않는다.

생성 결과에는 객체 식별자·종류별 개수·좌표 원점·문서 단위·범위·적용 설정과 경고가 담긴다. 작업 결과가 완료된 뒤 확인하고 한 번의 Undo로 되돌릴 수 있다. [EumCrawl](../eum-crawl/README.md)은 같은 PNU로 독립적으로 조회할 수 있다.

고급 설정을 접어도 값은 유지된다. 범위·옵션·지형 요청 한도를 만족하면 **연산 가능**으로 표시되며, 그렇지 않으면 공통 상태 영역에 이유가 표시된다.

## 주요 설정

| 설정 | 기본값과 동작 |
| --- | --- |
| 지형 표본 간격 | 레벨 12, 국내 표본 약 15m 간격. 13~15도 선택할 수 있으나 지역별 공급 여부가 다르다. 표본 간격은 측량 정확도가 아니며 Mesh·NURBS·Contour의 공통 높이장에 사용한다. |
| 도로 표시 | 켜짐. 끄면 도로 영역·도로 높이 보정·도로 형상을 만들지 않는다. 필지는 계속 수집한다. |
| 땅과 도로 분리 | 켜짐. 도로 아래 중복 땅을 만들지 않는다. 끄면 연속 땅 위에 같은 높이의 도로 면을 겹친다. |
| 도로 내리기·단차 | 켜짐, 200mm. 분리한 도로를 설정값만큼 내리고 공유 경계에 옆면을 만든다. 끄거나 0mm이면 같은 높이에서 역할만 나눈다. |
| 건물 층당 높이 | 3m. 원천의 양수 지상층수에 곱한다. |
| 높이 미확인 건물 | 6m. 현재 건물 원천에 높이가 없고 양수 층수도 없을 때 적용한다. |
| 건물 최소 면적 | 10㎡. 전체 원천 외곽에서 구멍을 뺀 평면 면적으로 판단하며, 0이면 크기로 제외하지 않는다. |
| Contour·간격 | 꺼짐·1m. 근접 주변 지형을 등고판으로 표현하고 건물 자리를 판 단위로 파낸다. 근접 영역을 켰을 때만 사용한다. |
| 건물 기초 분리 | 꺼짐. 켜면 본체와 기초를 별도 객체·레이어로 만든다. 두 방식의 지붕과 기초 바닥은 같다. |
| 근접 건물 파라펫·폭·높이 | 켜짐·300mm·300mm. 지붕 외곽과 중정 가장자리의 안쪽에 별도 Extrusion을 만든다. 폭·높이는 양수이며 근접 영역을 켰을 때만 사용한다. |

지형·도로·건물 모델의 **100mm 기준은 평면의 미세 영역을 정리하는 기준**이다. 원천 정리 후 남거나 근접 경계·등고판으로 나누며 생긴 작은 땅·도로 조각은 같은 구역의 이웃 역할로 합치므로 모델용 역할 경계가 달라질 수 있다. 원본 XY·선택 대지경계·근접 영역의 원호와 접선은 유지한다. 수직 도로 단차를 100mm 이상으로 제한하는 기준은 아니다.

## 근접 설계 영역과 건물

근접 영역은 기본 **ON**이다. OFF이면 근접 구분 없이 선택한 Mesh/NURBS 형식으로 전체를 만든다.

독립 대지마다 면적 중심에서 가장 먼 경계까지를 R로 잡고 같은 중심에 기본 **2R·최소 1.5R**의 원을 만든다. 겹친 원은 바깥 공통접선·원호로 감싸고 떨어진 묶음은 별도로 유지한다. 모델 범위에 들어오지 않으면 생성 전에 필요한 가로·세로를 안내한다.

Contour OFF의 Near 땅·분리 도로는 수직 옆면과 공통 수평 바닥을 가진 닫힌 NURBS 입체다. 상면 전체 최저점에서 설정 깊이만큼 내려가며 기본 **30m**다. 겹침 도로는 면으로 둔다. Far 지형은 선택한 형식의 면이다.

**건물 전체 윤곽이 근접 경계 안에 있고 닿지 않을 때만 Near 건물**이다. 경계에 닿거나 걸치면 전체를 Far로 만든다. Near 건물은 가벼운 Rhino Extrusion이며 Far는 선택한 형식이다.

모든 건물의 지붕은 건물 아래 전체 지형의 면적 가중평균에 원천·추정 높이를 더한 위치다. 일반 기초 바닥은 전체 지반의 최저점보다 **1m 아래**다. Near OFF나 Far도 같은 원칙을 사용한다. 급경사에서 건물 상부 일부가 지형에 묻힐 수 있으며 지붕을 임의로 올리지 않는다.

본체와 기초는 평균 지반 높이에서 나뉜다. 기본은 기초 바닥부터 지붕까지 하나의 객체이며, **건물과 기초 분리**를 켜면 본체와 기초가 별도 객체가 된다. 떨어진 외곽이 여러 개이면 각각 만든다. 유효한 겹침 건물을 삭제하지 않으며 Near에서 서로 겹친 건물 묶음은 가장 낮은 기초 바닥을 공유한다.

Contour를 끄면 지형을 파내지 않고 건물과 겹치게 둔다. 기초 깊이는 모델 표현을 위한 것이며 실제 구조 기초·지하층 자료가 아니다.

생성할 건물의 중심이 모델 범위 안에 있으면 전체 윤곽을 유지하므로 일부가 사각 범위 밖으로 나올 수 있다. 전체 지반에 필요한 자료는 내부적으로 더 취득하되 넓어진 범위의 건물을 추가로 생성하거나 출력 지형·XY 범위를 늘리지 않는다.

## Contour

Contour를 켜면 Near의 **주변 지형**을 우드락 판처럼 일정 간격으로 쌓는다. 기본 간격은 **1m**다. 각 판은 수평 상·하면과 일정한 단면을 가진 닫힌 Extrusion이다. 작은 돌출·섬은 생략해 아래 레벨이 드러나게 하며 중정과 건물 기초 구멍은 보존한다.

선택한 대지는 계단화하지 않는다. 인접 선택 필지를 합친 독립 대지마다 곡면 상면의 닫힌 NURBS 입체를 `Site`에 만들며, 그 안의 지형은 도로 구분·단차 없이 연속된다. 원본 도로 경계는 XY에 남는다.

- **도로 분리 ON:** 도로판은 땅판과 별도 객체·레이어다. 각 위치에서 드러난 도로 상판만 설정 단차만큼 얇아진다. 예를 들어 간격 1m·단차 200mm이면 노출 상판은 800mm다. 단차가 간격 이상이면 필요한 위 판을 제거하고 남은 판의 두께를 조절한다.
- **도로 분리 OFF:** 연속 땅판 위에 도로 면을 겹친다. 도로 내림은 적용하지 않는다.
- **건물 자리:** 선택 대지와 닿지 않는 Near 건물 아래에서, 가장 낮은 노출판의 바닥까지 판다. 완전한 평지에서도 적어도 한 판이 빠진다. 기초는 그 바닥에 놓고 지붕은 계단화 전 평균 지반 기준을 유지한다. Far나 선택 대지에 걸친 건물은 굴착하지 않는다.
- **하부:** 가장 낮은 상세 레벨 아래에 간격 두께의 지지판 2장과 나머지 두꺼운 기단을 만든다. 기본 깊이 30m·간격 1m라면 하부는 1m+1m+28m다. 깊이는 간격의 두 배보다 커야 한다. 대지 본체는 기단 윗면까지 내려오고 기단은 대지 아래도 받친다.

Near 외곽은 연속 지형에서 기단 윗면까지 내려오는 캡 없는 NURBS 외벽으로 막는다. 원호·접선 위치를 유지하고 도로 단차에서 나눈다. 판 옆면과의 겹침은 허용하며 수평으로 완만하게 변형하지 않는다. 작은 간격·큰 근접 영역·많고 복잡한 건물 윤곽은 판과 평면 연산을 늘려 계산 시간이 길어질 수 있다. 생성 전에 처리량 한도를 검사하며 간격을 자동으로 바꾸지 않는다.

생성 후 Far를 숨기거나 잠그고 Near·Site를 편집할 수 있다. 편집 후 경계·도로·건물의 자동 재연결은 제공하지 않는다.

## 출력 레이어와 정보

전체 모델은 아래 순서로 생성한다. 상위 `aha_topo_…`만 펼치고 하위 레이어는 접는다. `XY`는 기본 숨김이며 목록의 펼침 상태와 가시성은 별개다.

| 설정 | 상위 레이어 내부 |
| --- | --- |
| Near OFF | `TargetBoundary`, `Surfaces`, `Buildings`, `XY` |
| Near ON·Contour OFF | `TargetBoundary`, `Near`, `Far`, `XY` |
| Contour ON | `Site`, `Near`, `Far`, `XY` |

Near/Far 내부는 `Surfaces`, `Buildings` 순서다. 땅·도로·기단은 Surfaces 하위에서 구분하며 분리한 기초는 Buildings 하위 `Foundations`에 둔다.

파라펫은 `Near::Buildings::Parapets`에 별도 닫힌 Extrusion으로 만든다. 좁은 지붕에서는 띠가 합쳐지고 내부가 사라지면 지붕 전체를 돌출한다. 기존 지붕 높이는 유지하고 그 위로 설정 높이만큼 올라간다. 원천에서 확인한 실제 파라펫이 아닌 모델 표현이다. Contour·기초 분리와 무관하며 Far 건물과 XY 전용에는 만들지 않는다.

Contour OFF의 `TargetBoundary`는 지형에 투영한 대지경계를 직접 보유한다. Contour ON은 이 Curve 대신 `Site` 입체를 대지로 지정한다. 두 방식 모두 원본 평면 대지경계는 `XY::TargetBoundary`에 Z=0으로 남는다. 주변 필지·도로·건물의 원본 참조선도 XY에 둔다. XY 전용 생성에서는 XY만 표시하며 대지 외곽 Curve를 대지로 지정한다.

[Info](../info/README.md)로 생성 객체의 `aha.info`를 조회·편집하고, 보존된 PNU로 [EumCrawl](../eum-crawl/README.md)을 사용할 수 있다. 대상 대지와 그 XY 원본은 Near 여부와 무관하게 상세 정보다.

| 대상 | 기본 정보 | 상세 정보 |
| --- | --- | --- |
| 주변 필지·도로 필지 XY | 확보한 PNU·지번 표기·지목 코드 | Near와 겹치면 이미 확보한 지번주소 추가 |
| 생성 건물 본체·기초·XY | 관리번호·PNU·지상층수·높이·높이 근거·분류 상태 | Near 건물은 확보한 명칭·주소·지하층수·분류 코드 추가 |
| 땅·도로 면/판/입체 | AHA 종류(`kind`) | 동일 |

주소를 위해 추가 조회하지 않으며 없는 값을 추정하지 않는다. 건물의 도로명주소와 필지 지번주소는 구분한다. 같은 건물의 본체·기초·XY는 생성 당시 같은 정보를 갖지만 이후 편집을 자동 동기화하지 않는다. 입체가 없는 유효한 XY 참조선에는 생성하지 않은 모델 높이를 기록하지 않는다.

## 데이터의 의미

원본과 생성 형상의 정확도, 건물 높이 추정, 도로 지목 분류 및 지형 공급 경로는 [데이터와 한계](data.md)를 참고한다. Topo는 법규를 판정하거나 정보가 없는 주소를 별도로 찾아 보강하지 않는다.
