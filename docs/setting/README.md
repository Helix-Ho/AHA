# Setting

`AHA → Setting`, Topo 상단의 Setting 버튼 또는 `AHASetting`으로 연다. KEY와 일반 설정은 설치 폴더·Rhino 모델과 분리된 사용자 환경에 저장하며 재설치 후에도 유지한다.

## VWorld KEY

[V-WORLD 디지털트윈국토 API 인증키](https://www.vworld.kr/dev/v4apiRefer.do)를 발급받아 입력한다. 패널을 열면 macOS 보안 저장소의 KEY를 불러오며 기본은 숨김이다. **KEY 보기**를 켜면 내용을 확인할 수 있다.

- 저장된 KEY가 없으면 입력 후 **KEY 저장**을 누른다. 삭제 버튼은 비활성화된다.
- 저장된 KEY가 있으면 입력은 읽기 전용이고 저장 버튼은 비활성화된다. 변경하려면 **KEY 삭제** 후 새 KEY를 입력한다.
- **KEY 검증**은 표시된 KEY로 필지 한 건의 조회 가능 여부를 확인한다. 검증만으로 저장하지 않으며 모든 서비스·지역의 이용 가능성을 보증하지 않는다.

KEY를 모델 속성·MCP 결과·일반 설정·복사 주소에 포함하지 않는다. 보안 저장소 접근에 실패하면 덮어쓰기를 막기 위해 입력을 잠근다. Info와 PNU 기반 EumCrawl은 KEY 없이 사용할 수 있다.

## MCP 연결

MCP는 같은 컴퓨터의 클라이언트가 AHA 도구를 호출하도록 여는 로컬 통신 창구다. 기본은 OFF이며 필요할 때 켠다.

MCP를 켠 뒤 **주소 복사**로 얻은 URL을 사용하는 AI 도구의 MCP 설정에 등록한다.

**연결 확인**은 서버의 초기 응답을 확인하는 기능이다. 특정 AI가 등록을 마쳤거나 도구를 실제로 사용했다는 뜻은 아니다. AHA는 클라이언트의 AI 로그인이나 모델 선택을 관리하지 않는다.

실제 연결에는 패널에 표시된 주소를 사용한다. 서버가 꺼졌거나 시작에 실패했을 때 복사되는 주소는 저장된 설정값이므로 먼저 서버 상태를 확인한다.

## 포트

포트는 같은 컴퓨터에서 통신 대상을 구분하는 번호다. 기본은 18940, 설정 범위는 1024~65535다. **포트 적용** 시 기존 서버를 먼저 종료하고 새 주소로 시작한다. 포트를 여러 번 바꿔도 서버가 누적되지 않으며, 같은 포트 재적용은 서버를 다시 만들지 않는다. 새 포트가 이미 사용 중이면 서버는 꺼진 상태로 실패를 표시한다.

한 Rhino 프로세스에서 여러 문서를 열어도 서버는 하나다. 별도 Rhino 프로세스에서 동시에 MCP를 켜는 경우에만 다른 포트를 사용해야 한다. 일반 설정은 사용자별로 공유하므로 재시작이나 설정 적용 시 마지막 저장값을 읽는다. 포트 변경 후에는 클라이언트의 연결 주소도 갱신한다.

패널을 닫아도 켜진 MCP는 계속 작동한다. MCP를 끄면 서버와 MCP로 시작한 EumCrawl 조회는 중지하지만 Topo 연산·준비 결과는 유지된다. Rhino를 종료하면 모든 작업과 준비 결과를 정리한다.
